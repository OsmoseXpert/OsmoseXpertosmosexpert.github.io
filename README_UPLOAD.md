# OsmoseXpert – GitHub Pages release

Deze map is de volledige publicatiemap. Upload **de inhoud van deze map** naar de root van de GitHub Pages-repository.

- `index.html`, `CNAME` en `.nojekyll` moeten in de repositoryroot staan.
- Laat de routemappen (`diensten/`, `contact/`, enz.) intact.
- De oude `.html`-bestanden zijn kleine compatibiliteitsredirects.
- De mp4/webm-logoanimatie, centrale contactstijl, mobiele navigatie, slimme CTA-dock en Chatbase-integratie zijn inbegrepen.
- Pas bestanden pas aan na een eigen controle van deze release.

## Lokaal bekijken op Windows

Open CMD in deze map en voer uit:

```cmd
py -m http.server 8000
```

Open daarna `http://localhost:8000/`. Stoppen doet u met `Ctrl+C` in CMD.
